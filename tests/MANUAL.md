# 実機の確認リスト（Pixel・Chrome）

自動テストでは確かめられない、スマホでだけ分かる所。新しい版を公開した時と、年1回の見直しの時に確かめる。

## はじめて入れた時

- [ ] `https://<組織名>.github.io/` を Chrome で開く → メニュー →「ホーム画面に追加」（アプリとしてインストール）
- [ ] ホーム画面のアイコンから開く（上のアドレス欄が無い、全画面で開く）
- [ ] 機内モードにしてから開いても、画面が出る
- [ ] 設定 → データを守る の「保存の状態」が「登録済み」になっている（何回か使った後で）

## 操作

- [ ] シートを開いて、Android の「戻る」操作でシートだけが閉じる（アプリは閉じない）
- [ ] 候補箱の下の入力欄をタップ → キーボードの上に入力欄が見えている（隠れない）
- [ ] 日本語で「おーろら」→ 変換 → 確定の Enter を押しても、書きかけのまま保存されない。もう一度 Enter で保存される
- [ ] 続けて何件も書ける（1件入れてもキーボードが閉じない）
- [ ] アイコンを長押し → ショートカット（思いつき・今年・人生）が出て、それぞれ開く
- [ ] 文字の大きさ 150%・ダークテーマでも崩れない（候補箱の下の入力欄がタブに隠れない・設定の画面が横にはみ出さない）
- [ ] シートを開いたまま、案内（トースト）と［元に戻す］が見えて押せる
- [ ] 思い出の一言を書いている途中に暗い所をタップしても、シートが閉じない

## データを守る

- [ ] 設定 → 書き出す（共有）→ Google ドライブ に保存できる（ファイル名 `timebucket-backup-日付.txt`）
- [ ] 別のブラウザ（または Chrome のシークレットタブ）で開き、そのファイルを「ファイルから取り込む」→ 件数が一致
- [ ] 何か変更 → すぐアプリを閉じる（最近使ったアプリから消す）→ 開き直しても変更が残っている
- [ ] 新しい版を公開した後、「新しい版があります［更新する］」が出て、押すと新しい版になる（設定の版番号で確認）

## 日付を決めた経験の後

- [ ] 日付を過ぎた経験について、今年タブに「〇〇、行ってきましたか？」が出る → ［行った］→ 一言・手応え・写真リンクを残せる
